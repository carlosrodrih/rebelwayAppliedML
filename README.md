# Welcome to the Applied Machine Learning for VFX & 3D Repository

This repository contains all the **theory, notebooks, exercises, and Houdini tools** developed throughout the *Applied Machine Learning for VFX & 3D* course.  
Each branch represents a specific **week of the course** or a focused **topic**, keeping the material organized and easy to follow.

## Branch Index

- **computer_basics** *(Week 1)*  
  Python refresher, SOLID principles, design patterns, and the Shopping Cart exercise.

- **scikitlearn** *(Week 1)*  
  Introduction to Scikit-Learn and basic ML workflows.

- **experiment/dataio** *(Week 2)*  
  Data import/export workflows, Jupyter notebooks, Pandas and Seaborn introductions.

- **houdini** *(Week 2)*  
  A* pathfinding HDA, multi-agent logic, and step-by-step visual debugging.

## Assignments
- **week_1** – Shopping Cart modular exercise.  
- **week_2** – A* HDA extension and data extraction tasks.

Feel free to explore each branch to follow the progression of the course.
