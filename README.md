# Week 1: Python Refresher - Computer Basics

In **Week 1** of the **Machine Learning for VFX and 3D** course, we reviewed fundamental **Python** concepts and programming best practices for visualization and VFX projects.

## Topics Covered

- **Python Data Structures**: lists, tuples, dictionaries, and sets.  
- **SOLID Principles**: best practices for writing clean and maintainable code.  
- **Design Patterns**: applying basic patterns to organize code efficiently.  
- **Modules & File Organization**: how to split a project into multiple files and modules to keep it scalable.

## Practical Exercise: Shopping Cart

To put the concepts into practice, we developed a **Shopping Cart** project:

- Created multiple classes and functions across different files.  
- Implemented common cart operations: adding/removing products, calculating totals, etc.
